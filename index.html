                      how to play scattergories

                      the goal

                      come up with an answer for every category that starts with the round's letter. the trick: you only get full points if nobody else thought of the same answer.

                      getting started

                      1. one person types their name and makes a room. they're the host.
                      2. everyone else types their name and the 4-letter room code (or opens the invite link).
                      3. the host picks how many rounds and how long each one lasts, can change the categories, and hits start.

                      each round

                      1. everyone sees the same letter and the same list of categories.
                      2. type an answer for each category before the timer runs out. you don't have to fill them all in.
                      3. done early? press "i'm done!" and everyone else has 8 seconds left to finish.
                      4. when time's up, everyone's answers show side by side and get scored.

                      scoring

                      • 10 points for an answer nobody else had
                      • 5 points if someone else wrote the same answer
                      • 0 points if it's blank or doesn't start with the letter

                      spelling and capital letters don't matter when answers are compared, and "the", "a" and "an" at the start are ignored ("the beatles" and "beatles" count as the same).

                      disagreements

                      the host can tap any answer to throw it out (say, it isn't really a thing) or to let one through that the game rejected. tap it again to undo. everyone sees the change straight away.

                      winning

                      after the last round, the player with the most points wins. you can leave any time with "leave game", but your points will be lost.
